一分钟就能开始听

  1. 从 F-Droid（由源代码构建）或它的 GitHub 页面安装 Blazify。
  2. 打开应用，搜索歌曲、艺人或专辑。无需登录，马上就能播放。
  3. 如果想用自己的歌单和点赞，选择使用 Google 账号登录。这一步也可以一直跳过。

事先要知道的

Blazify 没有上架 Google Play，所以在 Android 上需要从 F-Droid 或 GitHub 安装。Premium 有电视、手表和智能音箱应用；Blazify 都没有，只支持车上的 Android Auto。曲库就是 YouTube Music 的曲库，那里能找到的歌，就是这里能播放的歌。手机里已有的歌也会和在线歌曲在同一个队列里播放。

Blazify 是一个独立项目，并非由 YouTube 或 Google 开发，也与它们没有任何关联。

常见问题

Blazify 真的免费吗？

是的。没有付费版，没有试用期，也没有广告。它是采用 GPL-3.0 许可证的开源软件，由加德满都的一位开发者 Rajendra Pandey 制作。

需要订阅 YouTube Music Premium 吗？

不需要。Blazify 不要求订阅。除非你想在应用里使用自己的音乐库，否则连 Google 账号都不需要。

能在 iPhone 和电脑上用吗？

能。Blazify 还可以在 iPhone、Windows 和 Linux 上运行。iPhone 版通过 SideStore 或 AltStore 安装，不经过 App Store。

我的收听会被跟踪吗？

不会。Blazify 不含任何广告、统计分析或跟踪库。
