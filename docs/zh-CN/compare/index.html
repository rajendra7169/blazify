Blazify 从何而来

Blazify 并非白手起家。它的流媒体核心建立在 InnerTune 以及由其发展而来的 Metrolist 之上，没有编写和维护这些项目的人，就不会有 Blazify。感谢他们每一个人。因为这些应用全都采用 GPL-3.0，这种在彼此成果之上继续构建的做法，正是许可证所允许的，只要成果同样保持开源。

Blazify 在此之上加入了自己的设计和功能，以及 iPhone、Windows 和 Linux 版应用。它由尼泊尔加德满都的一位开发者 Rajendra Pandey 制作。

常见问题

这些应用免费吗？

五款都是采用 GPL-3.0 许可证的免费开源软件。Blazify 没有付费版、没有广告、没有统计分析，也没有跟踪库。

其中哪些能在 iPhone 或电脑上运行？

五款之中只有 Blazify 可以，其他四款都是 Android 应用。iPhone 版 Blazify 通过 SideStore 或 AltStore 安装，Windows 和 Linux 版则从 rajendrapandey.info.np 上的 Blazify 页面获取。

换用后还能保留我的 YouTube Music 音乐库吗？

在 Blazify 里可以：用 Google 账号登录，你的音乐库、歌单和点赞都会一起带过来。登录是可选的，其他所有功能无需账号都能用。

Blazify 上架 Google Play 了吗？

没有。在 Android 上请从 F-Droid 或它的 GitHub 页面获取。

Blazify 是一个独立项目，并非由 YouTube 或 Google 开发，也与它们没有任何关联，同时与 Metrolist、OuterTune、InnerTune 和 ViMusic 没有隶属关系。
