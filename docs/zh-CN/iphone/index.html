四步完成安装

App Store 之外的应用需要借助侧载工具安装。SideStore 和 AltStore 都可以，两者都会用你自己的 Apple ID 为应用签名。

  1. 按照官网上的指南，在 iPhone 上安装 SideStore 或 AltStore。
  2. 在 iPhone 上打开 GitHub 中的最新 Blazify 版本，下载 Blazify.ipa。
  3. 用 SideStore 或 AltStore 打开下载的文件，Blazify 就会安装到主屏幕上。
  4. 每周刷新一次应用，具体见下文。

每周刷新

使用免费 Apple ID 时，Apple 允许侧载的应用运行七天，之后必须重新签名。刷新只需在 SideStore 或 AltStore 里点一下，你的音乐库、歌单和设置都会原样保留。SideStore 可以直接在手机上完成刷新，身边不需要电脑。如果过了一周忘了刷新，应用只是在刷新之前打不开而已。

事先要知道的

iPhone 版目前为 0.4.0 版本，比 Android 版起步晚，所以现阶段功能较少。它不在 App Store 上，因此更新方式和首次安装一样：下载新版本，用 SideStore 或 AltStore 打开。它的音乐来自 YouTube Music 曲库，YouTube Music 上没有的歌，Blazify 里也不会有。

常见问题

需要给 iPhone 越狱吗？

不需要。SideStore 和 AltStore 安装的是用你自己的 Apple ID 签名的应用，手机系统不会有任何改动。

要花钱吗？

不用。Blazify 免费，没有付费版，也没有广告。用免费 Apple ID 就能安装，唯一的代价是每七天刷新一次。

我的收听会被跟踪吗？

不会。Blazify 不含任何广告、统计分析或跟踪库。源代码以 GPL-3.0 许可证公开。

谁开发的？

尼泊尔加德满都的一位开发者 Rajendra Pandey。同一款应用也能在 Android、Windows 和 Linux 上运行。
