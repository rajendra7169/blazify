Blazifyを入手
Windows版Blazify

Windows用の無料音楽プレーヤー、広告なし

Windows版Blazifyは、YouTube Musicのカタログから選んだ曲を再生し、音楽に合わせて歌詞を表示し、ログインすればあなたのプレイリストも使えます。料金は一切かからず、広告も表示されず、管理者パスワードなしでインストールできます。

Windows版をダウンロード ほかのデバイス

パソコンでできること

すぐに始められるホーム画面

アプリを開けばすぐに再生できる音楽が並んでいます。聴きたいものをピンポイントで検索することもできます。

充実したプレーヤー

アルバムアートワークを中心にしたプレーヤー画面で、再生、一時停止、スキップ、シークができます。

同期歌詞

再生中の曲に合わせて歌詞が動くので、目で追いながら聴けます。

ビデオ表示

オンにすると、静止画の代わりに曲のミュージックビデオがプレーヤーの背後で再生されます。

デザイン設定

デスクトップの雰囲気や好みに合うまで、アプリの見た目を変えられます。

ログインすれば、あなたのライブラリも

Googleでログインすると、あなた自身のYouTube Musicライブラリとプレイリストを表示できます。ログインしなくても、検索と再生は使えます。

インストール方法

  1. 上のボタンから、rajendrapandey.info.npのBlazifyページを開きます。いつでも最新のデスクトップ版が置いてあります。
  2. Windowsインストーラーをダウンロードして実行します。管理者パスワードを求められないので、自分が管理者ではないパソコンでも使えます。
  3. Blazifyを開いて、何か再生してみましょう。オーディオエンジンが内蔵されているので、ほかに何もインストールする必要はありません。

現在のデスクトップ版は1.4.0で、2026年10月にリリースされました。

最初に知っておきたいこと

デスクトップ版はAndroid版より新しく、機能の数ではAndroid版のほうが多くなっています。YouTube Musicのカタログからストリーミングするためインターネット接続が必要で、YouTube Musicにない曲はBlazifyにもありません。インストーラーは上のリンク先のBlazifyページから入手してください。デスクトップ版のリリースごとに更新されています。

よくある質問

本当に無料ですか？

はい。有料プランも、試用期間も、広告もありません。BlazifyはGPL-3.0ライセンスのオープンソースソフトウェアです。

アカウントは必要ですか？

いいえ。検索と再生はログインなしで使えます。Googleでログインすると、あなた自身のYouTube Musicライブラリとプレイリストが加わるだけです。

再生履歴は追跡されますか？

いいえ。Blazifyには、広告、アナリティクス、トラッキングライブラリが一切含まれていません。

スマホ版はありますか？

はい。BlazifyはAndroidとiPhone、そしてLinuxパソコンでも動作します。ネパールのカトマンズに住む一人の開発者、Rajendra Pandeyが作っています。
