免費、無廣告聽 YouTube Music

Blazify 是一款免費的 Android 應用程式，播放 YouTube Music 曲庫中的音樂，歌與歌之間沒有廣告。關閉螢幕後照樣播放，可以把音樂存下來離線聆聽，不需要帳號，也不用訂閱。

沒有廣告

一首接著一首。沒有要略過的廣告，也不用買方案來去掉廣告，因為根本就沒有廣告。

背景播放、關閉螢幕也能播

鎖定手機或切換到其他應用程式，音樂照樣繼續，鎖定畫面上也有播放控制項。

離線下載

下載歌曲、專輯和播放清單，之後沒有網路也能播放。

逐字歌詞

來自多個來源的同步歌詞，逐字醒目標示，支援翻譯與羅馬拼音。

無縫播放，還有等化器

現場專輯一氣呵成，中間不會停頓。10 頻段等化器、13 種預設集、低音強化與音量平衡，幫你調出想要的聲音。

想要的話，帶上你的音樂庫

用 Google 帳號登入，就能帶入你自己的 YouTube Music 音樂庫、播放清單和喜歡的內容。其他功能不登入也都能用。

一分鐘就能開始聽

  1. 從 F-Droid（由原始碼建置）或它的 GitHub 頁面安裝 Blazify。
  2. 開啟應用程式，搜尋歌曲、藝人或專輯。不用登入，馬上就能播放。
  3. 如果想用自己的播放清單和喜歡的內容，選擇使用 Google 帳號登入。這一步也可以一直略過。

事先該知道的事

Blazify 沒有上架 Google Play，所以在 Android 上要從 F-Droid 或 GitHub 安裝。Premium 有電視、手錶和智慧喇叭的應用程式；Blazify 都沒有，只支援車上的 Android Auto。曲庫就是 YouTube Music 的曲庫，在那裡找得到的歌，就是這裡能播放的歌。手機裡現有的歌也會和串流歌曲在同一個佇列中播放。

Blazify 是獨立專案，並非由 YouTube 或 Google 製作，也與它們沒有任何關係。

常見問題

Blazify 真的免費嗎？

是的。沒有付費方案、沒有試用期，也沒有廣告。它是採用 GPL-3.0 授權的開源軟體，由加德滿都的一位開發者 Rajendra Pandey 製作。

需要訂閱 YouTube Music Premium 嗎？

不需要。Blazify 不會要求訂閱。除非你想在應用程式裡使用自己的音樂庫，否則連 Google 帳號都不需要。

iPhone 和電腦也能用嗎？

可以。Blazify 也能在 iPhone、Windows 和 Linux 上執行。iPhone 版是透過 SideStore 或 AltStore 安裝，不經過 App Store。

我的收聽紀錄會被追蹤嗎？

不會。Blazify 不含任何廣告、分析工具或追蹤程式庫。
