Blazify 從何而來

Blazify 並不是從零開始的。它的串流核心建立在 InnerTune，以及由它發展而來的 Metrolist 之上；沒有撰寫並維護這些專案的人，就不會有 Blazify。謝謝他們每一位。由於這些應用程式全都採用 GPL-3.0，像這樣在彼此的成果上繼續打造，正是授權條款所允許的，只要成果同樣保持開放。

Blazify 在此之上加入了自己的設計與功能，以及 iPhone、Windows 和 Linux 版應用程式。它由尼泊爾加德滿都的一位開發者 Rajendra Pandey 製作。

該選哪一款

Blazify

如果你想在 Android、iPhone、Windows 和 Linux 上使用同一個播放器，或習慣從 F-Droid（由原始碼建置）安裝應用程式，就選它。

Metrolist

如果你重視龐大的社群，就選它。它很活躍，在 GitHub 上約有 14,000 顆星。

OuterTune

如果你想要另一款仍積極維護的應用程式，就選它，F-Droid 和 IzzyOnDroid 都能取得。

InnerTune

Metrolist 的前身，也是 Blazify 基礎的一部分。它仍然可以安裝，但自 2024 年 9 月以來沒有再發布新版本。

ViMusic

自 2024 年 7 月起已封存並設為唯讀。如果你還在用它，上面任何一款活躍的應用程式都是更穩妥的選擇。

常見問題

這些應用程式免費嗎？

五款都是採用 GPL-3.0 授權的免費開源軟體。Blazify 沒有付費方案、沒有廣告、沒有分析工具，也沒有追蹤程式庫。

其中哪些能在 iPhone 或電腦上執行？

五款之中只有 Blazify 可以，另外四款都是 Android 應用程式。iPhone 版 Blazify 透過 SideStore 或 AltStore 安裝，Windows 和 Linux 版則從 rajendrapandey.info.np 上的 Blazify 頁面取得。

換用之後還能保留我的 YouTube Music 音樂庫嗎？

在 Blazify 可以：用 Google 帳號登入，你的音樂庫、播放清單和喜歡的內容都會一起帶過來。登入是選用的，其他功能不需要帳號也都能用。

Blazify 有上架 Google Play 嗎？

沒有。在 Android 上請從 F-Droid 或它的 GitHub 頁面取得。

Blazify 是獨立專案，並非由 YouTube 或 Google 製作，也與它們沒有任何關係，與 Metrolist、OuterTune、InnerTune 和 ViMusic 也沒有隸屬關係。
