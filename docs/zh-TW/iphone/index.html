iPhone 版 Blazify

iPhone 上的 YouTube Music 播放器，不需要 App Store

iPhone 版 Blazify 免費又開源。你用 SideStore 或 AltStore 自行安裝，之後就能搜尋、播放、看同步歌詞，沒有廣告；離開應用程式後音樂也會繼續播放。

iPhone 版能做什麼

搜尋與播放

在 YouTube Music 曲庫中找歌曲、專輯和藝人並播放，中間沒有廣告。

音樂庫與播放清單

收藏喜歡的歌，建立你自己的播放清單。

同步歌詞

歌詞跟著歌曲走，方便你跟著看、跟著唱。

背景播放

鎖定手機或開啟其他應用程式，音樂照樣繼續。

心情與曲風

不知道想聽什麼的時候，可以依心情或曲風瀏覽。

播放器設計

多種播放器外觀可選，其中還有卡帶造型，選擇之前都能即時預覽。

四個步驟完成安裝

App Store 以外的應用程式要用側載工具安裝。SideStore 和 AltStore 都可以，兩者都會用你自己的 Apple ID 替應用程式簽署。

  1. 依照官方網站上的說明，在 iPhone 上安裝 SideStore 或 AltStore。
  2. 在 iPhone 上開啟 GitHub 中的最新 Blazify 版本，下載 Blazify.ipa。
  3. 用 SideStore 或 AltStore 開啟下載的檔案，Blazify 就會安裝到主畫面上。
  4. 每週重新整理一次應用程式，做法見下方說明。

每週重新整理

使用免費的 Apple ID 時，Apple 允許側載的應用程式執行七天，之後就必須重新簽署。重新整理只要在 SideStore 或 AltStore 點一下，你的音樂庫、播放清單和設定都會原封不動。SideStore 可以直接在手機上完成重新整理，身邊不需要電腦。如果過了一週忘記重新整理，應用程式只是在重新整理之前打不開而已。

事先該知道的事

iPhone 版目前是 0.4.0 版，比 Android 版起步晚，所以現階段功能比較少。它不在 App Store 上，因此更新方式和第一次安裝一樣：下載新版本，再用 SideStore 或 AltStore 開啟。它的音樂來自 YouTube Music 曲庫，YouTube Music 上沒有的歌，Blazify 裡也不會有。

常見問題

iPhone 需要越獄嗎？

不需要。SideStore 和 AltStore 安裝的是用你自己的 Apple ID 簽署的應用程式，手機系統完全不會被更動。

要花錢嗎？

不用。Blazify 免費，沒有付費方案，也沒有廣告。用免費的 Apple ID 就能安裝，唯一的代價是每七天重新整理一次。

我的收聽紀錄會被追蹤嗎？

不會。Blazify 不含任何廣告、分析工具或追蹤程式庫。原始碼以 GPL-3.0 授權公開。

是誰做的？

尼泊爾加德滿都的一位開發者 Rajendra Pandey。同一款應用程式也能在 Android、Windows 和 Linux 上執行。
